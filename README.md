# AI Resume Intelligence

A workspace for parsing resumes, extracting skills, matching candidates to job descriptions, and generating recommendations.

## Project structure

- `backend/`: Python application code
- `data/`: resumes, job descriptions, skills, and datasets
- `models/`: trained model artifacts
- `notebooks/`: experiments and analysis
- `tests/`: automated tests
- `frontend/`: user interface

## Getting started

Activate the existing virtual environment, install dependencies, and run the backend entry point:

```powershell
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python backend\main.py
```
